이슈를 생성할 거야. 내가 구현할 기능을 설명할게.
아래 순서대로 진행해줘.

## 순서
1. 아래 형식으로 이슈 내용 작성
2. gh issue create 명령어로 GitHub에 자동 등록
3. 생성된 이슈 번호 확인
4. 이슈 번호 기반으로 브랜치 자동 생성
5. 생성된 브랜치로 자동 이동

## 이슈 형식
제목: [종류] 기능 한 줄 요약
종류: feat(새기능) fix(버그) refactor(리팩토링) chore(설정) docs(문서)

본문:
## 문제 정의
왜 이 이슈가 필요한가

## 구현 내용
- 구현할 내용 1
- 구현할 내용 2

## 기술적 고려사항
- 어떤 기술을 쓰는가
- 왜 이 방식인가

## 완료 조건

## gh 명령어 실행 형식
gh issue create \
--title "[종류] 제목" \
--body "본문 내용" \
--label "enhancement"

## 브랜치 생성 형식
git checkout -b 종류/#이슈번호-기능명
예시: feat/#1-github-repo-crud

## 주의사항
- 이슈 내용 나한테 먼저 보여주고 확인받은 후 gh 명령어 실행
- 브랜치 생성 전 main 브랜치인지 확인
- 브랜치명은 영어 소문자 + 하이픈만 사용
