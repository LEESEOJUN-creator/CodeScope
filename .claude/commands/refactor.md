현재 파일 또는 내가 지정한 파일을 아래 기준으로 리팩토링해줘.
기능 동작은 그대로 유지하고 구조만 개선해.

## 리팩토링 기준

1. 중복 제거
    - 반복되는 로직은 메서드로 추출
    - 공통 검증 로직은 별도 메서드로 분리

2. 메서드 크기
    - 한 메서드는 한 가지 일만 한다
    - 20줄 넘어가면 분리 고려

3. 네이밍
    - 메서드명만 봐도 무슨 일 하는지 알아야 함
    - 약어 사용 금지

4. JPA 최적화
    - N+1 발생 구조 제거
    - 불필요한 EAGER 로딩 제거
    - @Transactional 범위 최소화

5. 예외 처리
    - RuntimeException 직접 사용 금지
    - CustomException으로 교체
    - 에러 메시지 명확하게

## 주의사항
- 리팩토링 전후 동작이 동일한지 확인
- 테스트 코드 먼저 있는지 확인 (없으면 먼저 작성)
- 설명 못 하는 구조로 바꾸지 않는다
