아래 버그를 디버깅해줘.
내가 증상을 설명할게.

## 디버깅 순서

1. 증상 파악
    - 어떤 API에서 발생했는가
    - 에러 메시지가 무엇인가
    - 언제부터 발생했는가

2. 원인 후보 분석
    - JPA 관련: N+1, 트랜잭션 범위, LAZY 로딩
    - Redis 관련: TTL 만료, 직렬화 문제
    - Kafka 관련: Consumer 오프셋, Dead Letter Topic
    - 외부 API 관련: Rate Limit, 타임아웃

3. 확인 방법 제시
    - 어떤 로그를 봐야 하는가
    - 어떤 쿼리를 실행해야 하는가
    - 어떤 테스트로 재현할 수 있는가

4. 수정 방법 제시
    - 원인별 수정 코드 제시
    - 왜 이렇게 수정하는지 설명
    - 재발 방지 방법

## 주의사항
- 수정 전 반드시 원인을 먼저 파악한다
- 동작하면 됐지 식으로 수정하지 않는다
- 수정 후 테스트 코드로 검증한다
