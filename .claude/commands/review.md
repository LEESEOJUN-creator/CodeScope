현재 파일 또는 내가 지정한 파일을 아래 기준으로 리뷰해줘.

1. 컨벤션 확인
    - 생성자 주입 사용했는가 (@Autowired 금지)
    - DTO는 record로 작성했는가
    - 응답은 ApiResponse<T> 래퍼 사용했는가
    - 하드코딩된 값은 없는가 (application.yml로 관리)

2. JPA 확인
    - N+1 문제 발생 가능한 구조인가
    - @Transactional(readOnly = true) 조회 메서드에 적용했는가
    - 외부 API 호출이 @Transactional 범위 안에 있는가 (있으면 안 됨)

3. 보안 확인
    - 환경변수 직접 노출은 없는가
    - 민감한 값이 하드코딩되어 있지 않은가

4. 개선 제안
    - 위 문제 발견 시 수정 방법 제시
    - 설명 못 하는 코드가 있으면 표시해줘
